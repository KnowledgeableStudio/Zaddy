ZADDY COLLECTION — iZad Casanova
COMPLETE WEBSITE PROJECT

This archive contains the latest redesigned website source, original artwork,
hologram models, music, videos, build configuration, dependency lockfile,
tests, design notes, and the generated production website in dist/.

RUN LOCALLY
1. Extract the entire ZIP.
2. Open a terminal in the Zaddy-Collection folder containing package.json.
3. Install dependencies:
   npm ci
4. Start the development server:
   npm run dev
5. Open the local URL printed in the terminal.

The included Astro dependency requires Node.js 22.12.0 or newer and npm 9.6.5
or newer. Dependencies are installed locally with npm ci; this archive does
not include node_modules, development caches, or Git history.

OTHER COMMANDS
npm run build     Rebuild the production website in dist/.
npm run preview   Preview the production build locally.
npm test          Run the catalog rendering checks after building.

src/assets/       Original artwork and product images.
public/           Original videos, music, hologram, icons, and domain files.
docs/             Redesign notes and visual previews.
dist/             Included production build; regenerate after source edits.
